AUTOMATION INTEGRATIONS

Keep your automation engine.
Connect it to daily tabs.

agent-browser and browser-use keep their own automation semantics. Panerelay gives either one the same explicitly authorized existing-browser connection.

Explicit integration

Connect agent-browser to your everyday tabs.

Let CLI- or MCP-capable Agents use agent-browser on the tabs you explicitly authorize. Native snapshots, refs, screenshots, network tools, and diagnostics stay intact.

  • Works with shell-capable Agents
  • Background automation does not steal visible tab focus
  • Current profile and login state stay in the browser

Explicit integration

Connect browser-use
to your signed-in Chrome.

The browser-use CLI and CLI MCP keep their normal workflow. Panerelay routes Browser Harness to authorized tabs in your existing Chrome—without remote debugging or exported login state.

  • Browser Harness-backed CLI and CLI MCP in the unified Skill
  • Persistent private lane with visible release
  • Arbitrary Python SDK construction is outside this transparent path

04 · TRUST BOUNDARY

Access is not focus.
Control is never invisible.

Panerelay separates permission to see a site, authorization to include a tab, and the live lease required for mutation. Unsupported or unauthorized actions fail closed.

⌁

Credentials stay in the browser.

Panerelay reuses an authorized existing tab. It does not export cookies or log credentials, prompts, screenshots, page content, or request bodies by default.

×

No browser-process ownership.

Isolated profiles, launch-time proxy changes, and closing your browser remain outside an Extension-backed connection.

Compatibility, without hand-waving.

Exact evidence baselines: agent-browser 0.33.0 and browser-use 0.13.7 with Browser Harness 0.1.8. Edge remains Forwarded pending representative acceptance.
