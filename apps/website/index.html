browser context.

02 · TWO DIRECTIONS

Meet agents
where you work.

FROM ANY AGENT

Bring agent-browser into your daily tabs.

Any Agent that can run CLI or MCP tools can use agent-browser through Panerelay. Snapshots, locators, input, waits, screenshots, tabs, and diagnostics stay in the automation engine built for them.

  • Works with shell-capable Agents
  • Background automation does not steal visible tab focus
  • Current profile and login state stay in the browser

04 · TRUST BOUNDARY

Access is not focus.
Control is never invisible.

Panerelay separates permission to see a site, authorization to include a tab, and the live lease required for mutation. Unsupported or unauthorized actions fail closed.

⌁

Credentials stay in the browser.

Panerelay reuses an authorized existing tab. It does not export cookies or log credentials, prompts, screenshots, page content, or request bodies by default.

×

No browser-process ownership.

Isolated profiles, launch-time proxy changes, and closing your browser remain outside an Extension-backed connection.

Compatibility, without hand-waving.

agent-browser 0.33.0 is the pinned evidence baseline. Chrome has recorded version-specific classifications; Edge remains Forwarded pending representative acceptance.
