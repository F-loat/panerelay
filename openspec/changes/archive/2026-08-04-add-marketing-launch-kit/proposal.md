## Why

Panerelay now has a complete product, stable public website, and a sharper differentiator: users choose current-tab or all-supported-tabs authorization while active control remains separately visible and releasable. The project needs durable launch assets, an evidence-backed comparison page, and search-oriented entry points so people already looking for existing-browser Agent automation can discover and understand it.

## What Changes

- Add a bilingual public comparison page that explains when to use Panerelay, a managed or isolated browser, raw CDP attachment, or the Playwright Chrome Extension without presenting misleading winner claims.
- Add comparison-page navigation, canonical and social metadata, crawlable static content, sitemap coverage, and structured data for the queries Panerelay can honestly answer.
- Add a repository marketing launch kit with long-form launch posts, compact social variants, community-specific versions, reply patterns, SEO topics, factual claim sources, and an operating checklist.
- Add automated source and production-build contracts for comparison content, metadata, internal links, project-subpath assets, bilingual coverage, and claim-source links.
- Keep community participation contextual and useful; do not fabricate testimonials, mass-post identical copy, disparage alternatives, or make compatibility and security claims beyond checked-in evidence.
- Do not change browser attachment, permissions, protocol, control ownership, automation-engine semantics, or browser-process ownership. Panerelay still does not own isolated profiles, launch-time proxy changes, or the user's browser process.
- Keep agent-browser 0.33.0 as the accepted minimum and exact evidence baseline already recorded for the affected advanced-command and Provider compatibility groups; this change adds presentation and discovery only.

## Capabilities

### New Capabilities

- `marketing-launch-kit`: Durable, factual, reusable launch and community materials for English- and Chinese-language promotion.

### Modified Capabilities

- `project-website`: Add a bilingual comparison and SEO entry point while preserving the existing authorization, compatibility, privacy, accessibility, and static-delivery contracts.

## Impact

- Affects `apps/website/`, website source/build tests, crawler metadata, navigation, and social metadata.
- Adds repository-owned materials under `docs/marketing/` for launch and ongoing community operation.
- Uses existing website tooling and first-party static deployment; no new runtime service, analytics, model credential, browser permission, or automation dependency is introduced.
- References official Chrome, Playwright, Browser Use, agent-browser, and Panerelay compatibility sources; product behavior and compatibility classifications remain unchanged.
