# @panerelay/protocol

Shared versioned messages, runtime guards, transfer framing, and provider-neutral types for
PaneRelay.

The stable `0.1.0` package is released in lockstep with the PaneRelay Bridge, agent-browser
Provider, Extension, and setup CLI because cross-release protocol negotiation is not yet
supported. Most users should install PaneRelay through `@panerelay/setup` instead of depending on
the protocol directly.

See the [PaneRelay repository](https://github.com/F-loat/panerelay) for protocol RFCs, security
boundaries, and compatibility information.
