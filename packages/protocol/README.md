# @panerelay/protocol

Shared versioned messages, runtime guards, transfer framing, and provider-neutral types for Panerelay.

The package is released in lockstep with the Panerelay Bridge, browser registry,
administration CLI, agent-browser Provider, Extension, and setup package because
cross-release protocol negotiation is not yet supported. Most users should
install Panerelay through `@panerelay/setup` instead of depending on the
protocol directly.

See the [Panerelay repository](https://github.com/F-loat/panerelay) for protocol RFCs, security boundaries, and compatibility information.
